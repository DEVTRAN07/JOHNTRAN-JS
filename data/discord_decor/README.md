# STK Discord decoration assets

Các ảnh nhị phân không được lưu trong repository bot để tránh làm tăng dung lượng deploy.

Nguồn tài nguyên duy nhất:
- https://github.com/DEVTRAN07/Discord-decor
- https://raw.githubusercontent.com/DEVTRAN07/Discord-decor/main/

Bot chỉ tải menu.jpg hoặc file PNG của ID được chọn. Cache được đặt trên Persistent Disk thông qua JT_PERSISTENT_DIR (Render: /opt/render/project/data/stk-discord); local fallback là cache/stk-discord/. Xem docs/STK-DECORATIONS-API.md để biết chi tiết.
